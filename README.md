# Celda · Academia de hojas de cálculo

Aplicación inicial para un curso de ocho módulos de Excel Online y Google Sheets.

Registro, progreso individual, guías, plantillas XLSX, prácticas, exámenes y retroalimentación. Aprobación mínima de 80 por módulo.

Consulta [IMPLEMENTATION.md](IMPLEMENTATION.md) para instalación, configuración, alcance y pendientes. Esta versión es una base en desarrollo; todavía no está desplegada ni lista para certificación.
